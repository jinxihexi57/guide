# 启动方式

前后端都要起来才能正常使用：后端提供 API，前端提供页面。

## 前提条件

- Python 3.10+
- Node.js 16+（需能在终端直接运行 `node` / `npm`）
- 已配置 API 密钥：
  - `backend/.env`（LLM、高德 Web 服务 Key 等）
  - `frontend/.env`（高德 JS API Key、后端地址）

可参考示例文件自行复制：

```powershell
cd D:\agent\helloagents-trip-planner
Copy-Item backend\.env.example backend\.env
Copy-Item frontend\.env.example frontend\.env
```

然后编辑这两个 `.env`，填入真实密钥。

## 方式一：一键同时启动前后端（推荐）

在项目根目录执行：

```powershell
cd D:\agent\helloagents-trip-planner
npm install
cd frontend; npm install; cd ..
npm run dev
```

或直接双击 / 运行根目录脚本：

```powershell
.\start.ps1
# 或
.\start.bat
```

启动成功后访问：

| 服务 | 地址 |
|------|------|
| 前端页面 | http://localhost:5173 |
| 后端 API | http://localhost:8000 |
| API 文档 | http://localhost:8000/docs |

停止：在运行窗口按 `Ctrl + C`。

## 方式二：前后端分开启动

适合排查问题，或只改某一端时使用。需要开两个终端。

### 1. 启动后端

```powershell
cd D:\agent\helloagents-trip-planner\backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
```

也可用 uvicorn：

```powershell
uvicorn app.api.main:app --reload --host 0.0.0.0 --port 8000
```

看到服务监听 `8000` 端口即表示后端已启动。

### 2. 启动前端

另开一个终端：

```powershell
cd D:\agent\helloagents-trip-planner\frontend
npm install
npm run dev
```

浏览器打开 http://localhost:5173 。

## 环境变量要点

### 后端 `backend/.env`

| 变量 | 说明 |
|------|------|
| `LLM_API_KEY` | 大模型 API Key |
| `LLM_BASE_URL` | 大模型接口地址 |
| `LLM_MODEL_ID` | 模型名称 |
| `AMAP_API_KEY` | 高德 Web 服务 Key |
| `PORT` | 后端端口，默认 `8000` |

### 前端 `frontend/.env`

| 变量 | 说明 |
|------|------|
| `VITE_API_BASE_URL` | 后端地址，默认 `http://localhost:8000` |
| `VITE_AMAP_WEB_KEY` | 高德 Web 端 JS API Key |

## 常见问题

1. **`git` / `node` / `npm` 找不到**  
   软件已安装但当前终端仍报错时，关掉终端重开；若仍不行，完全退出 Cursor 再开。

2. **后端虚拟环境失效**  
   若 `.venv` 是在别的电脑创建的，删掉后按「方式二」重新 `python -m venv .venv` 并安装依赖。

3. **前端能开、生成计划失败**  
   先确认后端 `8000` 已启动，再检查 `backend/.env` 里的 LLM / 高德 Key 是否正确。

4. **端口被占用**  
   - 后端改 `backend/.env` 的 `PORT`，并同步改前端 `VITE_API_BASE_URL`  
   - 前端可在 `frontend` 目录用：`npm run dev -- --port 5174`
